Get started

From clone to first video.

chalk is a set of Claude Code skills and agents on a deterministic Node and Python pipeline. Install it once, then open the repo in Claude Code.

Requirements

What it needs.

Node 22 or laterthe CLI and pipeline
FFmpeg, ffprobe and Chromerendering and delivery
Python 3.10–3.13 with kokoro-onnx and soundfilenarration
HyperFrames and its skillsrender and transcription
pdftotext and tesseractPDF and scanned-PDF ingest (optional)
manim, plus TinyTeX or BasicTeXmaths scenes (optional)
STEP 1

Install

The doctor checks the whole toolchain and says what is missing.

install
$ git clone https://github.com/OlixIgnacious/chalk.git
$ cd chalk
$ npm install
# narration needs Python 3.10–3.13
$ uv venv --python 3.12 .venv
$ uv pip install --python .venv/bin/python kokoro-onnx soundfile
$ export HYPERFRAMES_PYTHON="$PWD/.venv/bin/python"
$ npx hyperframes skills
$ npx chalk assets
$ npx chalk doctor
STEP 2

Make something

Open the repo in Claude Code; the skills are found automatically. Your own script is a source too.

claude code
/chalk-long path/to/chapter.md --notebook
/chalk-long my-script.md --pack essay
/chalk book.epub --chapter 4 --segments 5
/chalk-short docs/chapter01.md
STEP 3 · OPTIONAL

Or drive the pipeline

It runs every stage whose inputs changed and stops at the next gate, saying exactly what it needs.

pipeline
$ npx chalk pipeline long-output/my-chapter --doc docs/my-chapter.md --notebook
$ npx chalk status long-output/my-chapter
# after reading the outline, scripts and grounding report
$ npx chalk pipeline approve long-output/my-chapter --scripts
$ npx chalk pipeline long-output/my-chapter
STEP 4 · OPTIONAL

Or use the control panel

A local panel for the whole build: a Plan, Build, Check stepper, a console per agent, and the gates where only you can approve.

control panel
$ uv pip install --python .venv/bin/python -r ui/requirements.txt
$ npm run ui
