How it works

Plan. Build. Check.

A build runs in three phases. The pipeline stops for you twice: once to approve the scripts before anything is rendered, and once to watch the finished video.

Grounding

Every line cites its paragraph.

On every run, the grounding agent asks one question of each narrated line and each claim on screen: does it say only what its source block says?

Narration · segment 02From December, the library stays open until nine on weekdays.
Supported · ¶ 3
Source · ¶ 3Beginning 1 December, weekday opening hours will extend to 9 pm.
Checked at the source

And the source is checked too.

A separate check asks whether the source is right, once per version of it. A contradicted claim stops the build until the source is fixed or you waive it. Waivers are yours; no agent writes them.

Reviewed before rendered

Gates are not advisory.

Rendering before the teaching has been reviewed is the expensive mistake. Every stage hashes its inputs, so a changed script redoes only that segment's voice onward.

The agents

Nine agents. None sees what it doesn't need.

No agent reaches the network unless its definition says so. Two do.

chalk-research

Writes a research brief for a topic with no source document: short paragraphs, each attributed to one fetched page, its date and the sentence it rests on.

network: true
chalk-factcheck

Checks the source itself, once per version: numbers, dates, names, quotations, superlatives, cause and effect, each against evidence.

network: true
chalk-grounding

Checks every narrated and on-screen claim against the block it cites, and every number against the script that produced it.

chalk-learner

Reads the scripts before anything is voiced, then watches the build the way its audience would.

chalk-frames

Writes one segment's frames from its approved script and narration timings. One agent per segment, in parallel.

chalk-frames-reviewer

Looks at three stills at every reveal and reports clipping, overlap, small or fast text and low contrast.

chalk-notebook-reviewer

Opens the notebook cold, runs every cell, tries its own inputs and says where it breaks.

chalk-reviewer

Finds what makes a build weak for its genre, and which file in the repo let it through.

chalk-resolver

Reads every report, finds where they disagree, and settles each conflict.

The eval

Mechanical where it can be.

The eval scores a build on its shape's criteria, its pack's and the shared ones. When the reviewer finds a gap the eval passed, the fix is a new criterion and a fixture that fails it.
