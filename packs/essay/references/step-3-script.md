# Step 3 for an essay: the script

Read `core/references/step-3-script.md` for the two-layer form; this adds the essay's rules.

- **One line on screen at a time.** `visual:` is a title card or a quotation card (tier 1); the display layer
  is the line itself. Sparse: a scene of two or three lines with `{pause}` between them.
- **Short sentences** (Y3): average 14 words or fewer, none over 24. Read each line aloud.
- **Quotations** in the display layer carry quote marks and their attribution in the same line (Y2):
  `display: "Benjamin Franklin wrote: \"Lost time is never found again.\""`. The spoken layer says the name too.
- **The return** (the last scene) uses a word or the image of the first (Y4).
- **No code, no tables, no running example** (Y5; E2 is waived). A number is fine when the source states it,
  and it is fact-checked like any other.
- Lines about the video itself ("save this for tomorrow morning") cite `[pipeline]`.

**Gate:** `chalk eval <out> --text` passes the essay group, G1 and E1; every quotation's block is supported in
`facts.md`.
